# AllThatCapture

Windows용 **고화질 화면 캡처 · 화면 녹화(MP4/GIF)** 데스크톱 앱입니다.

영역 지정 캡처, 단축키, 시스템 트레이 상주, 다국어(한/영/일)를 지원합니다.  
녹화·GIF 변환에는 FFmpeg를 사용합니다.

## 다운로드

이 저장소의 [Releases](../../releases)에서 최신 포터블 패키지(`AllThatCapture-v*-Portable.zip`)를 받으세요.  
압축을 풀고 `AllThatCapture_v*.exe`를 실행하면 됩니다. (.NET 런타임 포함)
